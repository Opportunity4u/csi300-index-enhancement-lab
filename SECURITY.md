# Security policy

## Supported version

Security fixes are applied to the latest revision of the default branch.

## Reporting

Do not open a public issue containing credentials, tokens, personal data or
licensed datasets. Contact the repository owner privately through their GitHub
profile and include only the minimum reproducible technical detail.

The project intentionally contains no broker authentication or automated live
order submission. Please report any change that accidentally exposes secrets,
reads credentials from unsafe locations or submits orders without an explicit
review boundary.
