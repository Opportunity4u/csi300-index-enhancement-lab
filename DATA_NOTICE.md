# Data notice

This repository does not redistribute the underlying historical equity prices,
official index files or vendor datasets used in the illustrative research run.
Only small aggregate tables and charts are included.

Users provide their own normalized CSV files and retain responsibility for:

- having the right to use those files;
- using adjusted or total-return prices when required;
- aligning fundamentals to their actual publication dates;
- supplying dated, point-in-time index membership and benchmark weights;
- documenting delistings, suspensions and other availability constraints.

The deterministic synthetic-data generator is included solely so the code path
can be reproduced without licensed market data.
